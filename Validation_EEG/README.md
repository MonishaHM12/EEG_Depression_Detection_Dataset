# Validation EEG Dataset

This directory contains EEG recordings collected from **five adult volunteers** for validation of the proposed system described in:

**“Multiclass Depression Detection from Prefrontal EEG Signals Using Deep Learning Models.”**

## Participants

The dataset contains recordings from five participants, identified using anonymous study-specific identifiers:

* `V01`
* `V02`
* `V03`
* `V04`
* `V05`

Each participant's EEG recording is provided as a separate CSV file.

## EEG Acquisition

The EEG recordings were collected using an **8-channel EEG headset** with a sampling rate of **250 Hz**.

The recorded channels are:

`Fp1, Fp2, F3, F4, O1, O2, Fz, Pz`

### Recording Parameters

| Parameter          | Value                            |
| ------------------ | -------------------------------- |
| Number of channels | 8                                |
| Sampling rate      | 250 Hz                           |
| File format        | CSV                              |
| EEG channels       | Fp1, Fp2, F3, F4, O1, O2, Fz, Pz |

## File Format

The directory contains the following files:

```text
Validation_EEG/
├── README.md
├── V01.csv
├── V02.csv
├── V03.csv
├── V04.csv
└── V05.csv
```

Each CSV file contains the following columns:

```text
pkt_num, Fp1, Fp2, F3, F4, O1, O2, Fz, Pz, timestamp
```

| Column      | Description                                             |
| ----------- | ------------------------------------------------------- |
| `pkt_num`   | Packet/sample number provided by the acquisition system |
| `Fp1`       | EEG signal recorded from the Fp1 channel                |
| `Fp2`       | EEG signal recorded from the Fp2 channel                |
| `F3`        | EEG signal recorded from the F3 channel                 |
| `F4`        | EEG signal recorded from the F4 channel                 |
| `O1`        | EEG signal recorded from the O1 channel                 |
| `O2`        | EEG signal recorded from the O2 channel                 |
| `Fz`        | EEG signal recorded from the Fz channel                 |
| `Pz`        | EEG signal recorded from the Pz channel                 |
| `timestamp` | Timestamp associated with the recorded sample           |

The EEG signal values are provided in the raw numerical format generated by the EEG acquisition system.

## Consent and Anonymization

Written informed consent was obtained from all five participants prior to data collection, including consent for public sharing of anonymized EEG data for research purposes.

The publicly available files have been anonymized. The following system-generated identifiers have been removed:

* Researcher ID
* Experiment ID
* Session ID
* User ID
* Device ID

Participants are represented only by the anonymous study-specific identifiers `V01`–`V05`.

## Purpose

The recordings in this directory were collected specifically for **validation of the proposed EEG-based depression detection system** described in the associated research article.
