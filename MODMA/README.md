# MODMA EEG Dataset

This directory contains the **MODMA (Multi-modal Open Dataset for Mental-disorder Analysis)** EEG data used in the study:

**“Multiclass Depression Detection from Prefrontal EEG Signals Using Deep Learning Models.”**

## Dataset

The dataset included in this directory is:

**EEG_3channels_resting_lanzhou_2015**

The dataset contains resting-state EEG recordings from the publicly available MODMA dataset.

The MODMA dataset is a **third-party dataset** and was not collected by the authors of the present study. The data are provided here for reproducibility of the analyses reported in the associated research article.

## EEG Channels

The `EEG_3channels_resting_lanzhou_2015` dataset contains three EEG channels:

* FP1
* FP2
* FPz

The original dataset and its acquisition details should be referred to for complete information about the data collection and preprocessing.

## Original Dataset

The MODMA dataset is described in:

> Cai, H. et al. A multi-modal open dataset for mental-disorder analysis. *Scientific Data* 9, 178 (2022).

**DOI:** https://doi.org/10.1038/s41597-022-01211-x

For complete information regarding the MODMA dataset, including its collection, participant information, ethical procedures, and data-use conditions, please refer to the original publication and the official MODMA dataset documentation.
